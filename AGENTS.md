# Regras de Delegação — Análise de Imagens (Lobby)

- SEMPRE que a tarefa envolver análise de imagens, capturas de tela, screenshots, prints, fotos ou qualquer conteúdo visual, delegue ao subagente **InnerLinho** usando a tool `task` com `subagent_type: "innerlinho"`.
- Passe a ele o caminho do arquivo de imagem e o contexto do que precisa ser analisado.
- **AGUARDE** o InnerLinho retornar a análise completa antes de continuar a tarefa.
- Use a análise retornada como base para prosseguir com a resposta, diagnóstico ou implementação.
- Nunca tente analisar imagens diretamente com o modelo principal — a análise de imagens é responsabilidade exclusiva do InnerLinho.
